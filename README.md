# Habit Tracker

A responsive habit tracking web application built using HTML5, CSS3 and JavaScript.

## Features
- Add and remove habits
- Mark habits complete for the current day
- Current streak calculation
- Weekly 7-day progress view
- LocalStorage persistence
- Responsive design for mobile and desktop

## How to Run
Open `index.html` in any modern web browser. No server or installation is required.
